Questions, answered

The essentials for anyone moving from Blogger or Blogspot.

Can I use my own domain?
Yes. Connect a domain such as blog.yourcompany.com in Blog Settings → Domains, add the CNAME record shown, and SSL is automatic.
How many blogs can I manage?
One account holds one blog for free and up to five blogs on Pro, all managed from the same login.
Do I need to install anything?
No. Blognice runs entirely in your browser — no hosting to arrange, no plugins to install, and no updates to apply.
Can I export my content?
Yes. Owners download a full export any time: posts and pages as Markdown, images, subscribers.csv, and comments.json.
Is Blognice open source?
Yes. Blognice is open source under the AGPL-3.0 license, so you can self-host it free or use the hosted service.
Can I import an existing Blogger blog?
Yes. Upload your Blogger backup file in Settings → Advanced → Import from Blogger. Posts and pages arrive with their tags, original dates, and drafts; uploading the same file again skips what is already there. Both the classic Blogger export and the Google Takeout file work — see the import guide.
